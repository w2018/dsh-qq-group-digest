批次触发

触发阈值 batch.threshold
单群累积到多少条消息就冻结成一批去总结，默认 100。
冻结宽限期 batch.freezeGraceMs
毫秒。到阈值后再等这么久，把陆续到达的消息一起收进同一批。
缓冲上限 batch.maxBuffer
单群内存里最多缓存多少条，超出后丢最旧的。
最长等待 batch.maxWaitMs
毫秒。冷清群攒不到阈值时，最多等这么久也强制总结一批。

总结模型

提供商 / 模型
留空表示使用 DSH 当前配置的默认模型。列表来自 DSH 的 LLM 服务。
温度 model.temperature
0–2，越小越稳定，总结场景建议 0.2–0.4。
最大输出 model.maxTokens
单次总结最多生成多少 token，默认 1200。
请求超时 model.timeoutMs
毫秒。超时会按重试次数重来。
失败重试 model.retries
0–10 次。重试全部失败时降级为原始摘录并继续投递。
历史总结条数 model.historyCount
0–10。把该群最近 N 次总结作为上下文喂给模型，避免重复叙述。0 = 不带历史。
历史字符上限 model.maxHistoryChars
0–20000。历史总结拼进提示词时最多占多少字符。
