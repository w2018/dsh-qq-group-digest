> **版本号**：增加逻辑是`逢九进一`，例如`v1.0.9` 升版本 `v1.1.0`

> **其它**：架构、出包、扩展清单与排错速查见文末 **附录**（`接手/继续开发先读`），本文档必需进`git版本控制`

## 🔴 更新本文档时必须遵守的结构约束（强制）

1. **倒序**：新条目**插到版本区顶部**（最新在最前），**禁止**追加到末尾。
2. **标题**：`## vX.Y.Z ｜ YYYY-MM-DD —— 一句话主题`（主题 ≤ 40 字，细节写进正文）。
3. **分类标签**：每条变更必须以 `[新增]` `[优化]` `[修复]` `[破坏性变更]` 之一开头；
   `[说明]` 仅限**出包号 / 兼容性提示**等元信息，且每个条目最多 1 条。
4. **一条一要点**：每条 **≤ 3 行**，只写「问题 → 结论/做法」，**不写**推导过程与验证输出。
5. **禁止冗余**（违反即视为未完成）：
   - 不写构建/检查结果（`vue-tsc` / `lint` / `cargo check` 通过等）；
   - 不写「沙箱无显示器 / 待真机确认」（见下方通用约定）；
   - 不写「未推送 / 未打标签 / 未触发 CI」（只在发布条目里写一次）；
   - 不重复他条已写过的内容 —— 写「详见 vX.Y.Z」即可；
   - 不贴命令输出、日志片段、实测 JSON。
6. **出包号**写在正文首行：`**出包**：文件包名_版本号.后缀`。

## 通用约定（各条目不再重复）

- 🔴 **GUI 交互**：沙箱无显示器，交互/手感**必须由用户真机确认** —— 不得声称已验证交互。
- 🔴 **发布纪律**：默认只本地提交；`git push` / 打标签 / 触发 CI **需用户逐次明确许可**。
- 🔴 **改动时**：前端 / 后端 / 侧车任一处改动都**必须重新出包**才生效。


## v0.3.0 ｜ 2026-10-25 —— 新增独立 HTTP 网页服务：配置 / 日志 / 总结记录三页

**出包**：dsh-qq-group-digest_v0.3.0（DSH 插件包，本地 link 安装，无独立出包文件）

- [新增] **HTTP 网页服务**：独立 `http.createServer`，默认关闭、默认端口 1213、默认监听 0.0.0.0、默认开启密钥验证（随机生成，仅存掩码）；端口被占用只记错误不阻塞插件。关闭不影响 DSH 设置页与 WS 管线。
- [新增] **配置页**：与 DSH 设置页功能对齐的九张卡片（运行状态 / 网页服务 / 监听 / 过滤 / 批次 / 模型 / 提示词 / 投递 / 存储），脏字段提交、保存即热生效、支持撤销与恢复初始配置。
- [新增] **日志页**：级别 / 群号 / 关键字 / 时间范围筛选，SSE 实时推送，导出 `.jsonl`，分页加载；日志按天落盘 `logs/<日期>.jsonl`，默认保留 7 天。
- [新增] **总结记录页**：按群分组，每条记录渲染完整 Markdown 文档（标题 / 要点 / 参与成员表 / 投递状态），支持复制、下载 `.md`、看原始文本、上下条翻页。
- [新增] **Markdown 渲染**：零依赖本地渲染器 `lib/summarize/markdown.js` 与前端 `static/md.js`，先转义再渲染防 XSS，`javascript:`/`data:` 链接被拦截。
- [新增] **AI 精细版总结**：`summary.aiDetail` 开关，打开后每批再调一次模型产出 800–2000 字长文；失败自动回退本地渲染，绝不影响投递。
- [新增] **提示词可编辑**：`prompt.system` 支持界面改写与一键恢复默认；默认提示词抽成 `DEFAULT_SYSTEM_PROMPT` 常量（722 字符，与旧实现逐字一致）。
- [修复] **多群合并超长截断**：原先把多个群的总结合并成一条 QQ 消息，容易撞上单条字数上限被截断。改为**每群各自渲染、各自发送一条独立消息**；单群超长才分段，某群失败不影响其它群，dryRun 与失败兜底也按群分文件。
- [优化] **投递结果按群回填**：历史记录的 `delivered`/`failed` 改为按群分别回填，不再用一个全局结果覆盖所有群。
- [优化] **设置页最近报告按群分块**：每个群一块（群名 + 条数 + 成功/失败标记），不再拼成一整段长文本。
- [修复] **settings.json 写错目录**：`storage.dir` 为空时 `storageRoot` 回落到 `$DSH_HOME` 根目录，配置「保存成功」却读不回来。改为先 `resolveConfig` 再取路径。
- [修复] **勾选开启后端口不监听**：通用 `POST /settings` 只重建运行态、不重新 listen，而重启监听只写在 `/http` 专用端点里，于是网页端勾选「开启」显示已保存却始终连不上。改为 `httpServer` 段任一字段变化即 `restartHttp()`，恢复初始配置同样触发停止监听。
- [修复] **静态目录存在后首页 404 用例失效**：改为请求必然不存在的路径断言 404 与 `cache-control: no-store`。
## v0.2.0 ｜ 2026-10-25 —— 新增信息过滤：关键词模糊匹配与按成员排除

- [新增] **关键词过滤**：消息文本包含任一关键词（子串模糊匹配、不区分大小写）即丢弃，不进入总结批次。
- [新增] **按成员排除**：分群维护排除成员名单，其发言不计入总结；设置页「信息过滤」卡片两步下拉（先选群拉成员列表，再搜索选择成员）。
- [新增] **成员选择**：新增 `GET /api/qq-digest/members?groupId=` 路由与 `groupMemberList` action，成员选择支持昵称 / 群名片 / QQ 号快速搜索。
- [优化] **成员列表布局**：成员选择由原生下拉改为紧凑滚动列表（行高 28px、限高 180px 自适应宽度），消除大面积空白；空列表 / 搜索无匹配 / 拉取失败各有明确提示。
- [优化] **数据自动刷新**：状态与最近报告改为 5 秒轮询自动刷新，不再需要切页重进；保存 / 忙碌期间暂停轮询并做在飞去重，避免重复请求。
- [优化] **过滤可观测**：丢弃原因计入 `dropReasons`（`keyword` / `excluded-sender`），可在运行状态里看到过滤量。
- [修复] **关键词保存后丢失**：`sanitizeOverride` 静默丢弃白名单外字段，旧后端不认 `listen.keywords` 导致「显示已保存其实没存」。改为 POST 返回 `droppedFields`，前端有丢弃即报错而非假成功。
- [修复] **成员拉取 unknown route**：`/members` 路由随插件载入，热重载只换 Runtime 不重载 index.js。新增 `BACKEND_VERSION` 与能力清单，版本不一致时页头直接提示重启 DSH；拉取失败也给出可操作文案。
- [修复] **关键词大小写被改写**：配置层不再强制转小写，保留用户原始输入，匹配时才忽略大小写。
- [修复] **孤儿排除名单**：不再监听的群，其成员排除名单自动丢弃，设置页不残留无效芯片。

## v0.1.0 ｜ 2026-10-25 —— 初始版：QQ 群消息按阈值总结并私聊投递

**出包**：dsh-qq-group-digest_v0.1.0（DSH 插件包，本地 link 安装，无独立出包文件）

- [新增] **群消息采集**：连 NapCat OneBot11 正向 WS，按群白名单采集，`(group_id, message_id)` 双层 LRU 去重、`real_seq` 排序与缺口标注。
- [新增] **批次触发**：每群独立状态机，`threshold` / `maxBuffer` / `maxWaitMs` 三条件任一满足即冻结，`freezeGraceMs` 抗乱序抖动。
- [新增] **总结与降级**：走 `ctx.llm.stream`，凭证/代理/路由全由 DSH 管理；路由三级回退，失败指数退避重试，耗尽后降级为原始摘录仍投递。
- [新增] **报告投递**：多群按群名/群号编号成一份报告，超长按行分段，段间间隔防风控；全失败兜底写 `outbox/failed-*.md`。
- [新增] **设置界面**：注册 `settings.section`，七张卡片；保存即校验→落盘→热重建运行态，不重启 DSH；折叠卡片仍显示启动/连接徽章。
- [新增] **群进度指示**：群芯片前显示 `[已累计/阈值]`，阈值优先取 `batch.perGroupOverride`。
- [新增] **历史总结上下文**：每群 `summaries/<群号>.json` 存最近 20 条，每次总结附带此前 `historyCount` 条；先落历史再投递，投递结果回填。
- [新增] **侧边栏入口**：`ui.sidebarEntry` 开关，注册 `main` + `sidebar.panellist`，老宿主回退 `sidebar.footer.action`，轮询跟随开关变化。
- [新增] **热重载**：`lib/` 整树复制到 `generations/` 再 `import` 绕过 ESM 缓存，新一代起来才停旧的；未总结消息经 `snapshotPending`/`restorePending` 继承。
- [修复] **投递必然失败**：`Pipeline` 早于 WS client 构造，`actions` 一直为 `undefined`，报 `Cannot read properties of undefined (reading 'sendPrivate')`；改由 `Runtime` 在 `createActions` 后回填。
- [修复] **保存配置丢 pending**：热重建把缓冲区直接清空；新增快照/恢复，且恢复必须放在 `start()` 的 `running = true` 之后，否则达阈值批次被静默丢弃。
- [优化] **发言人称谓**：提示词硬约束昵称一律用【】包裹，降级摘录同步改格式。
- [优化] **精简代码**：删除客户端不调用的 `/config`、`/model`、`/outbox` 路由与 `outboxFiles`、`buildAndDeliver`、`oldestArrival`、`groupHistory`、`MessageStore.read`、`onAttempt` 等死代码；`listen.ignoreTypes` 因 `post_type !== 'message'` 恒丢弃而移除；`/settings` 去掉无人消费的 `overridden`/`overlayKeys`/`baseGroups`/`defaults`。
- [说明] 单元测试 85 例全绿（`node --test "test/*.test.js"`）；真实 DSH 内 `POST /api/qq-digest/reload` 需重启一次 DSH 才挂上新路由，之后改 `lib/**` 点按钮即可。
