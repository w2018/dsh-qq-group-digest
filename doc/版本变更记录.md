## 🔴 更新本文档时必须遵守的结构约束（强制）

1. **倒序**：新条目**插到版本区顶部**（最新在最前），**禁止**追加到末尾。
2. **标题**：`## vX.Y.Z ｜ YYYY-MM-DD —— 一句话主题`（主题 ≤ 40 字，细节写进正文）。
3. **分类标签**：每条变更必须以 `[新增]` `[优化]` `[修复]` `[破坏性变更]` 之一开头；
   `[说明]` 仅限**出包号 / 兼容性提示**等元信息，且每个条目最多 1 条。
4. **一条一要点**：每条 **≤ 3 行**，只写「问题 → 结论/做法」，**不写**推导过程与验证输出。
5. **禁止冗余**（违反即视为未完成）：
   - 不写构建/检查结果（`vue-tsc` / `lint` / `cargo check` 通过等）；
   - 不写「沙箱无显示器 / 待真机确认」（见下方通用约定）；
   - 不写「未推送 / 未打标签 / 未触发 CI」（只在发布条目里写一次）；
   - 不重复他条已写过的内容 —— 写「详见 vX.Y.Z」即可；
   - 不贴命令输出、日志片段、实测 JSON。
6. **出包号**写在正文首行：`**出包**：文件包名_版本号.后缀`。

## 通用约定（各条目不再重复）

- 🔴 **GUI 交互**：沙箱无显示器，交互/手感**必须由用户真机确认** —— 不得声称已验证交互。
- 🔴 **发布纪律**：默认只本地提交；`git push` / 打标签 / 触发 CI **需用户逐次明确许可**。
- 🔴 **改动时**：前端 / 后端 / 侧车任一处改动都**必须重新出包**才生效。


## v0.1.0 ｜ 2026-10-25 —— 初始版：QQ 群消息按阈值总结并私聊投递

**出包**：dsh-qq-group-digest_v0.1.0（DSH 插件包，本地 link 安装，无独立出包文件）

- [新增] **群消息采集**：连 NapCat OneBot11 正向 WS，按群白名单采集，`(group_id, message_id)` 双层 LRU 去重、`real_seq` 排序与缺口标注。
- [新增] **批次触发**：每群独立状态机，`threshold` / `maxBuffer` / `maxWaitMs` 三条件任一满足即冻结，`freezeGraceMs` 抗乱序抖动。
- [新增] **总结与降级**：走 `ctx.llm.stream`，凭证/代理/路由全由 DSH 管理；路由三级回退，失败指数退避重试，耗尽后降级为原始摘录仍投递。
- [新增] **报告投递**：多群按群名/群号编号成一份报告，超长按行分段，段间间隔防风控；全失败兜底写 `outbox/failed-*.md`。
- [新增] **设置界面**：注册 `settings.section`，七张卡片；保存即校验→落盘→热重建运行态，不重启 DSH；折叠卡片仍显示启动/连接徽章。
- [新增] **群进度指示**：群芯片前显示 `[已累计/阈值]`，阈值优先取 `batch.perGroupOverride`。
- [新增] **历史总结上下文**：每群 `summaries/<群号>.json` 存最近 20 条，每次总结附带此前 `historyCount` 条；先落历史再投递，投递结果回填。
- [新增] **侧边栏入口**：`ui.sidebarEntry` 开关，注册 `main` + `sidebar.panellist`，老宿主回退 `sidebar.footer.action`，轮询跟随开关变化。
- [新增] **热重载**：`lib/` 整树复制到 `generations/` 再 `import` 绕过 ESM 缓存，新一代起来才停旧的；未总结消息经 `snapshotPending`/`restorePending` 继承。
- [修复] **投递必然失败**：`Pipeline` 早于 WS client 构造，`actions` 一直为 `undefined`，报 `Cannot read properties of undefined (reading 'sendPrivate')`；改由 `Runtime` 在 `createActions` 后回填。
- [修复] **保存配置丢 pending**：热重建把缓冲区直接清空；新增快照/恢复，且恢复必须放在 `start()` 的 `running = true` 之后，否则达阈值批次被静默丢弃。
- [优化] **发言人称谓**：提示词硬约束昵称一律用【】包裹，降级摘录同步改格式。
- [优化] **精简代码**：删除客户端不调用的 `/config`、`/model`、`/outbox` 路由与 `outboxFiles`、`buildAndDeliver`、`oldestArrival`、`groupHistory`、`MessageStore.read`、`onAttempt` 等死代码；`listen.ignoreTypes` 因 `post_type !== 'message'` 恒丢弃而移除；`/settings` 去掉无人消费的 `overridden`/`overlayKeys`/`baseGroups`/`defaults`。
- [说明] 单元测试 85 例全绿（`node --test "test/*.test.js"`）；真实 DSH 内 `POST /api/qq-digest/reload` 需重启一次 DSH 才挂上新路由，之后改 `lib/**` 点按钮即可。
